Page 03

Four kinds of work.

This page lists offers. It does not name clients, count projects, or claim years.

  1. 01

    Application features

    A change inside a product that already has people using it. The new piece fits the system that is there.

  2. 02

    Internal tools

    Software a team uses to do its own work. The point is a task finished with fewer wrong turns.

  3. 03

    Debugging a system someone else started

    Find the fault, name it, and fix the smallest true piece. The notes say what was wrong and what remains.

  4. 04

    Written handoff notes

    A map for the next person. Decisions, names, and the edges of the system, written so the work can continue.

Ship the smallest true thing.
