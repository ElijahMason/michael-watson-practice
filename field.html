Plate 04, Field

Notes from the practice.

  1. Follow one path.

    Pick a task a person does. Walk it from the screen to the stored data and back. Write that path before you propose a change.

  2. Put the limit in the first note.

    A date, a library, a rule. If it is real, it belongs where someone will see it early.

  3. Hold, then clarify.

    Reliability is the first delivery. A clearer interface is the next edit. The screen should say what the system is doing.
